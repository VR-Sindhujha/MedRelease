# MEDRELEASE

Healthcare Software Configuration & Release Management.

MedRelease is an enterprise-style SCM and release lifecycle platform for healthcare software organizations. It manages configuration items, change control, baselines, versions, deployments, GitHub development activity, and audit history.

## Current implementation

Phase 1 establishes the backend foundation:

- React/FastAPI project separation
- FastAPI API
- SQLAlchemy database layer
- SQLite local development
- PostgreSQL-ready configuration
- JWT authentication
- Secure password hashing
- Protected APIs
- Organization membership isolation
- Initial organization management
- Backend test foundation
